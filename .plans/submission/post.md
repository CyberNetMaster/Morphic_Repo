# Public post

Morphic is an open-source design tool for load-bearing printed parts. You describe the part in plain English: where it is held, where the loads act, how big it may be, and the stress and deflection limits. Morphic turns that into a problem you check on a drawing, then optimizes a shape for six real materials across FDM, SLS and metal printing, using only datasheet values shown with their sources. It ranks the passing designs by mass, explains the winner with numbers that are checked against the results, and exports STL, SVG, DXF, a PDF report and a run bundle that reruns to the same answer.

The shapes come from topology optimization, which adds material where strain energy is high and removes it where it is low, the same principle as bone remodeling. For an RC car suspension arm, carbon-fibre nylon wins at 3.93 g, 39 % lighter than a straight-strut design sized to the same limits by the same solver. For a drone arm the same material wins at 13.3 g, and a design agent that explores changes to the part found a taller section that passes at 10.49 g. The physics is checked against beam theory (under 0.4 % error at the stated mesh), a published benchmark, and a stress-concentration formula, and 201 automated tests run on every build.

It is honest about what it is not. The model is static and 2D, there is no fatigue, impact or physical test yet, and the hard cases are stated on every result, not hidden. Commercial tools also compare materials, but this one is open, cited, checked and reproducible, and adding a material costs almost nothing. Built solo at the OSI Hackathon in two days, MIT licensed.
